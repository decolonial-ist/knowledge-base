# sources/ - source files awaiting intake into the archive

Found a document that the archive does not have and that has no link? Put the file here in your pull request and cite it in the text: `(Citation: sources/file-name.pdf)`. We create a card in the archive, assign a number, replace the citation and remove the file from here. In `main` this folder is always empty.

---

Знайшли документ, якого немає в архіві, і в нього немає посилання - покладіть файл сюди у своєму pull request і пошліться на нього в тексті: `(Citation: sources/імя-файлу.pdf)`. Ми заведемо картку в архіві, видамо номер, замінимо зноску й приберемо файл звідси. У `main` ця папка завжди порожня.

---

Нашли документ, которого нет в архиве, и у него нет ссылки - положите файл сюда в своём pull request и сошлитесь на него в тексте: `(Citation: sources/имя-файла.pdf)`. Мы заведём карточку в архиве, выдадим номер, заменим сноску и уберём файл отсюда. В `main` эта папка всегда пуста.
